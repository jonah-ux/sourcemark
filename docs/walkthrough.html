Sourcemark · synthetic field guide

The citation that refuses to die.

Move the file. Edit the sentence. Test the agent. Sourcemark keeps the trail from a claim back to the evidence, then tells you when that trail drifts.

python3 -m pip install 'git+https://github.com/jonah-ux/sourcemark.git@v0.4.0'

A tiny tool for a very modern problem.

Answers outlive the file layout they were born in. Sourcemark stores enough context to find the evidence again, and enough session detail to catch a citation the agent never actually read.

03 / Why teams keep it around
Survives ordinary churn

Git renames, inserted lines, edited wording, and untracked moves are part of the synthetic path.

Catches confident nonsense

Unread lines, made-up files, and unsourced links are visible failures instead of polished fiction.

Stays local and inspectable

Python 3.11+, standard library only, SQLite ledger, MIT license. The fixture is synthetic by design.

To reproduce the illustrated incident, first clone the tagged source: git clone --branch v0.4.0 --depth 1 https://github.com/jonah-ux/sourcemark.git, then cd sourcemark. The demo file is included in that checkout; it is not a CLI subcommand.

Want the source? Open README.md or run python3 demos/demo.py from a checkout. The walkthrough is intentionally self-contained so it can be read before installing anything.

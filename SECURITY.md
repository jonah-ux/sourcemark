# Security

Sourcemark stores short excerpts of the text it cites. Excerpts pass through a secret redactor before they are written, and database citations store only a fingerprint of sensitive values.

Report a vulnerability privately through GitHub's "Report a vulnerability" button on this repository. Please do not open a public issue for security reports.

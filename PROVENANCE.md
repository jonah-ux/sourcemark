# Provenance

Sourcemark was written for this repository by Jonah Helland with Claude Code, starting 2026-10-02.
It contains no code copied from other projects. The anchoring approach (quote + context selectors,
position hints, fuzzy re-anchoring) follows the publicly documented design of the W3C Web Annotation
selectors and the Hypothesis "fuzzy anchoring" write-ups; the implementation is original.

Every change landed as a reviewed pull request with one commit per file. Accuracy claims in the README
come from an evaluation harness run against real-world repositories and agent sessions; that harness
and its raw results are kept outside this repository because they contain private material. The test
fixtures shipped here are synthetic.

Released under the MIT license.
